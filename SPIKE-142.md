## What was built (deliverable 1)

- `tsconfig.base.json`: added `"types": ["node"]`. This file ships as the `core-typescript` template (`src/manifest/index.ts:102`), so the change also lands in every scaffold; `core-typescript` already installs `@types/node`, so it's safe there, but it is a template change existing projects will see as drift in `diff`/`update`.
- `tsconfig.json`: `include` swaps `tsup.config.ts` → `tsdown.config.ts`.
- `tsdown.config.ts` (new), replacing `tsup.config.ts`: two configs like before. Required non-default: `fixedExtension: false` (tsdown defaults to `.mjs` on `platform: 'node'`, package.json names `.js`). `banner: '#!/usr/bin/env node'` on the cli build only; `dts: { compilerOptions: { incremental: false } }` on the index build.
- `.oxlintrc.json` (new, generated from the resolved ESLint config, see table): plugins `eslint, typescript, unicorn, import, node, jsdoc, vitest`; `categories.correctness: "off"` so the rule set is exactly the parity set (182 root rules + overrides); `options.typeAware: true`; `options.reportUnusedDisableDirectives: "error"`. Overrides: `node/no-top-level-await` on for `src/**/*.ts` minus `cli.*`/specs; `no-console` off for `cli.*`, `scripts/**`, configs; 6 vitest rules on `*.spec.*`/`*.test.*`; all 21 type-aware rules off for `test/e2e/**`, vitest configs, `opt-in/**`, `*.mjs|js|cjs` (mirrors antfu `ignoresTypeAware`).
- `.oxfmtrc.json` (new): tabs, width 2, `printWidth: 100` (from `.editorconfig max_line_length`), semi, singleQuote, `arrowParens: always`, `trailingComma: all`, `quoteProps: consistent`, `sortPackageJson: false`; ignores dist, CHANGELOG.md, release-please manifest, lockfile, `.agent-guild`, `.specify`, `CLAUDE.md`, `AGENTS.md`, `.claude`, `.agents` (same carve-outs the ESLint config had).
- `package.json`: `build: tsdown`, `dev: tsdown --watch`, `lint: oxlint && oxfmt --check` (formatting stays a lint gate, as it was under antfu), `lint:fix: oxlint --fix && oxfmt`, `format: oxfmt`; `lint-staged` → `*.{js,mjs,cjs,ts,mts,cts}: [oxlint --fix, oxfmt]`, `*.{json,jsonc,md,yaml,yml}: oxfmt`, `*.css: stylelint --fix` unchanged; `eslint.config.mjs` removed from `files`.
- Build output checked against the files: `dist/cli.js` first line `#!/usr/bin/env node` and mode `rwxr-xr-x`; `dist/index.js` first line `import { existsSync } from "node:fs";` (no shebang); `dist/index.d.ts` present. `node dist/cli.js list --json` is byte-identical to the tsup build on main. `index.d.ts` exports the same names; shape differs (tsdown emits `export declare const ...` + `export type {...}`, tsup emitted one `export { type ... }` list).
- tsdown prints `WARN TypeScript 7.0 does not yet have a stable API and is experimental. Some options will be unavailable.` on every build. The dts emit succeeded regardless.

Nothing stopped the spike. The only red is in tests (see Verification log): `pin-drift.spec.ts` and the `pack.spec.ts` tarball snapshot.
